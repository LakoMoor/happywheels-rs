### c8 strap break threshold (finding, 2026-11-21)

velocity clamp of 200 m/s caps it; 300 and 1000 give the same value), and an ejected elf is no longer tied to the chest strap at
all (`elfChestRemove` re-hangs it on a ball). So the threshold path (`Santa::check_joints` → `break_strap`) is only covered by
calling `break_strap` directly (`c8_break_strap_releases_the_elf_chest`); no natural scenario reaches 0.4 yet.
